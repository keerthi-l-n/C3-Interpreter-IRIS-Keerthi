# C3-Interpreter-IRIS-Keerthi
Web calculator for my IRIS project applying my proposed decision path (MMA ÷ MCA ratio, then homocysteine) to second-tier newborn screening results, to separate propionic acidemia, methylmalonic acidemia and B12-related causes. Based on my own Python/Human-GEM simulation; HTML coded with help from Claude. Research prototype, not for clinical use.
